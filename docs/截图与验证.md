### 怎么重新生成

截图脚本不进仓库（依赖本机的 Chrome/Edge 和 CDP，属于一次性工具）。做法：

1. 准备一个隔离的演示项目，避免动到自己的导图：

   ```bash
   mkdir -p /tmp/mldemo/maps
   echo '{"version":1,"mapsDir":"maps"}' > /tmp/mldemo/mindleaf.json
   cp examples/demo.mindmap.json /tmp/mldemo/maps/演示.mindmap.json
   node bin/mindleaf.mjs serve --project /tmp/mldemo --port 7801 --no-open --no-token
   ```

2. 用无头浏览器连 CDP 截图。要点（踩过的坑都在这）：

   - 启动参数：`--headless=new --disable-gpu --no-sandbox --user-data-dir=<临时目录>`
   - 尺寸：`Emulation.setDeviceMetricsOverride { width: 1440, height: 900, deviceScaleFactor: 2 }`
     → `Page.captureScreenshot` 得到 2880×1800
   - `Runtime.evaluate` 的 `expression` 必须是**字符串**，不能直接传函数；
     字符串模板里的 `\d` 会被吞掉，正则里写 `[0-9]`
   - 5 个标签页以上的 Edge 进程会互相干扰，跑之前先 `pkill -f "remote-debugging-port=9"`

3. 导出后用 `sips -Z 1440`（手机图 `-Z 720`）缩到 2× 以内的目标宽度，体积能降一半。

## 自动化验证

```bash
npm test           # node --test，全部用例
npm run test:e2e   # 只跑真实浏览器的 e2e（没有 Chromium 会自动跳过）
```

| --- | --- |

| `ops.test.mjs` | 12 个 op：节点增删改移、颜色与字体、批注、附图、关联线、setDoc、原子批处理 |
| `markdown.test.mjs` | Markdown 互转、链接抽取、中文与折行 |
| `layout.test.mjs` | 布局：三种方向、折行、框宽高、文字垂直居中、连线端点、标签避让、SVG 输出 |
| `export.test.mjs` | 7 种导出格式、PNG/JPEG 编码、矢量 PDF |

| `http.test.mjs` | 全部接口：状态、地图 CRUD、ops、导出、SSE、附图上传、访问口令、自动退出 |
