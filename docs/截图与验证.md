### 浏览器端检查的不是"看起来像"，而是这些事实

- DOM 里节点数 = 文档节点数，SVG 有 `data-node-id` 供定位；
- 三栏几何（侧栏 272px / 检查器 332px / 画布 ≥ 700px）、无横向滚动；
- 状态栏高度 24–34px、画布视口高度 > 500px（**历史 bug**：`banner[hidden]` 退出网格后，
  自动排布把画布塞进了 `auto` 行，高度塌成 0，状态栏被撑成 1fr 行 —— 已改为显式 `grid-row` 并加回归断言）；
- 每个按钮都有可读名称（`aria-label` / `title` / 文本）；
- 文字对比度 ≥ 4.5（浅色 `--ink-3` 曾只有 2.99，已调到 #64708a ≈ 4.96）；
- 节点文字不溢出节点框、节点矩形两两不重叠、`fit` 后整图在视口内（用 `getBBox` 量）；
- 真实鼠标/键盘事件（CDP `Input.dispatchMouseEvent` / `dispatchKeyEvent`）：双击编辑、`Tab` 加子节点、`Delete` 删除、拖拽改父节点；
- 外部写入（模拟 agent）在 1.8s 内被页面感知：要么自动合并，要么弹出提示条；
- 控制台零报错；
- **切换布局（向右/向左/双向）后**：每条树连线的起点/终点仍贴在父/子节点边缘（用路径 `d` 与节点 `rect` 的 SVG 坐标逐条比对），
  所有节点仍在视野内且内容居中（历史 bug：左侧布局的连线终点少算/多算了一个节点宽度，导致连线扫过整张图）。
